## Pubblicazione con GitHub Pages

1. Crea su GitHub un repository pubblico chiamato `marcello-cv-site` senza inizializzarlo con README, licenza o `.gitignore`.
2. Collega il repository locale al nuovo remoto:

   ```powershell
   git remote add origin https://github.com/MELLO77777/marcello-cv-site.git
   git push -u origin main
   ```

3. Nel repository GitHub apri **Settings → Pages** e imposta **Deploy from a branch**, con branch `main` e cartella `/(root)`.

Il sito sarà disponibile all'indirizzo `https://mello77777.github.io/marcello-cv-site/`.
